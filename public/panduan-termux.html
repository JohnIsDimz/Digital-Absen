1️⃣ INSTALL TERMUX (JANGAN DARI PLAY STORE!)

Play Store versi lama (2 tahun tidak update). Install dari F-Droid:

Buka Chrome HP: https://f-droid.org/en/packages/com.termux/ Download APK → Install → Buka Termux

2️⃣ SETUP AWAL TERMUX (Copy Paste 1 per 1)

pkg update -y && pkg upgrade -y pkg install nodejs git nano termux-tools tmux -y node -v # Harus v18+ / v20+ ✅ npm -v termux-setup-storage # Klik ALLOW / IZINKAN pkg install unzip -y

3️⃣ MASUKKAN PROJECT KE TERMUX

PILIH SALAH 1 CARA:

CARA A - GitHub (Paling Mudah):

cd ~ git clone https://github.com/username/absensi-siswa.git cd absensi-siswa

CARA B - Dari Download ZIP:

cd ~ unzip ~/storage/downloads/absensi-siswa.zip -d ~ cd ~/absensi-siswa ls -la # Harus ada package.json, src/, public/

CARA C - Jika file sudah di HP:

cp -r ~/storage/downloads/absensi-siswa ~/ cd ~/absensi-siswa

4️⃣ INSTALL & BUILD

cd ~/absensi-siswa npm install # Jika HP RAM kecil & error: # npm install --no-audit --no-fund cp .env.example .env nano .env # Edit jika perlu, simpan CTRL+X → Y → Enter # Reset database jadi NOL (0 data) echo '{"settings":null,"kelas":[],"guru":[],"siswa":[],"sesiAbsen":[],"absensi":[],"izin":[],"rekapSikap":[]}' > data/database.json # Build npm run build # Jika ada error TS tapi dist/ terbuat, itu NORMAL # Karena pakai transpile-only ls dist/ # Harus ada dist/index.js ✅

5️⃣ JALANKAN SERVER

PILIHAN 1 - Mode Dev (Rekomendasi untuk Termux, auto-reload, ignore error TS):

npm run dev

Output sukses:

🎓 AbsenSiswa Neo-Brutalist System v0.5 🌐 Server: http://localhost:3000 📅 Tahun: 2026 - 2026/2027

PILIHAN 2 - Mode Production (Hemat RAM):

npm run build npm start

Jika Port 3000 sudah dipakai:

pkill -f node npm start
